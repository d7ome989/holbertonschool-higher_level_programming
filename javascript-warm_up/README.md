# JavaScript - Warm up

## Description
This project is an introduction to JavaScript scripting using Node.js.
It covers the basics of writing and running a JavaScript script from the
command line, in the same way we did scripting with Python.

## Learning Objectives
- How to run a JavaScript script
- How to create constants with `const`
- How to print output with `console.log`
- Why the first line of a script is the shebang `#!/usr/bin/node`

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Files are interpreted on Ubuntu 20.04 LTS using `node` (14.x)
- All files end with a new line
- The first line of every file is exactly `#!/usr/bin/node`
- Code is `semistandard` compliant
- All files are executable

## Files

| File | Description |
|------|-------------|
| `0-javascript_is_amazing.js` | Prints "JavaScript is amazing" using a constant named `myVar` |

## Usage
```bash
chmod +x 0-javascript_is_amazing.js
./0-javascript_is_amazing.js
```

Output:
JavaScript is amazing
